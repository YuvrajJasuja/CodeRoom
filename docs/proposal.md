## Problem Statement

Collaborative programming is vital in computer science education, peer reviews, and remote pair programming. Traditional methods suffer from friction, such as manual code sharing over chat platforms or manual file merges, leading to version discrepancies and lost productivity.

## Solution

**CodeRoom** provides a zero-friction, web-based collaborative IDE where developers can:
- Instantly create isolated coding rooms with unique Room IDs.
- View live code updates synchronized in real time with sub-100ms latency.
- Track active room participants with dynamic user presence avatars.
- Sync editor states automatically for late-joining participants.
